# Optional Player Car Sprites

Place transparent, upward-facing top-down PNG car sprites here:

- `wedge-racer.png`
- `muscle-coupe.png`
- `tiny-formula.png`

Recommended source size is roughly `128x192`, centered, with no text, background, border, or shadow baked into the file. The game will load any sprites that exist and fall back to the canvas-drawn car when a file is missing or fails to load.
